# Agent rules for this repo

- Base branch: `master`. Every change goes through a pull request; agents never merge.
- Issue keyword: `Closes #N` when a PR completes its issue, `Refs #N` otherwise.
- This repo is public. Never add content from any employer, client or private repository, any person's name other than the owner's, private file paths, or secrets.
- No agent signature lines in commits, pull requests or comments.
